# BirdNET V3 model licensing and redistribution policy

## Bound authority

This policy is specific to **BirdNET+ V3.0 Developer Preview 3.1**, Zenodo
record [20703646](https://zenodo.org/records/20703646), DOI
[10.5281/zenodo.20703646](https://doi.org/10.5281/zenodo.20703646). It does not
make a general claim about other BirdNET versions or releases.

## Published terms and open issue

The release-specific [BirdNET V3 developer-preview repository](https://github.com/birdnet-team/birdnet-V3.0-dev)
and the retained [`TERMS_OF_USE.txt`](LICENSES/BIRDNET_V3_PREVIEW_TERMS_OF_USE.txt)
for Preview 3.1 describe the preview models as **CC BY-SA 4.0** and impose
additional prohibited-use conditions. The terms say those prohibitions override
permissive license aspects. The retained file is the exact object published
with Zenodo record 20703646; its published MD5 is
`d5949262d80b5749b49927767579b5f2`.

The current general BirdNET package [repository documentation](https://github.com/birdnet-team/birdnet)
describes its models more broadly as **CC BY-NC-SA 4.0**. The difference
between that general description and the release-specific Preview 3.1 terms is
an **OPEN_ISSUE**. This repository does not interpret or reconcile those terms
and does not claim legal clearance.

## Scope of the root license

The root Apache-2.0 license covers only original project-authored source code
and firmware. It does not license BirdNET model weights, labels or other model
data, reconstructed or transformed model artifacts, quantized models, or
Vela-generated model artifacts. It also does not license external audio, SDKs,
compilers, runtime libraries, or other third-party material.

## Operational redistribution policy

Acquire authoritative BirdNET inputs directly from the official upstream
release. Reconstruct derived artifacts locally. Until the applicable
redistribution terms are explicitly reconciled, this public project does not
redistribute official model binaries or derived model/Vela binaries. Do not
commit or redistribute them for convenience.
